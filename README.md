# Curso Básico de Python - WoMakersCode

Repositório com os materiais e exercícios do **Curso Básico de Python** promovido pela [WoMakersCode](https://womakerscode.org/).

## Sobre o curso

O objetivo deste curso é apresentar os fundamentos da linguagem Python de forma prática, acessível e introdutória, voltado especialmente para quem está começando na área de tecnologia.

## Conteúdo abordado

- Introdução ao Python
- Variáveis e tipos de dados
- Operadores
- Estruturas condicionais
- Laços de repetição
- Funções
- Orientação a objetos
